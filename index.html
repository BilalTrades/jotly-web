A FEW GOOD QUESTIONS

Before your first trade.

Is jotly really free?

Yes. jotly is free to use with no subscription. The source code is available on GitHub under the MIT license.

Where do I download the Windows app?

Open the latest GitHub release and look under Assets for a Windows installer or portable executable. Choose the app file, not the source-code ZIP. Windows 10/11 and Microsoft Edge WebView2 are required. Builds may be unsigned; read the release notes before installing.

Does jotly connect directly to my broker?

No. You can import broker CSV exports or enter trades manually. The included MT4/MT5 scripts export local CSV files; you select and import those files in jotly. This is not a live broker API connection or an automatic trading tool.

Is my trading data encrypted or backed up automatically?

Your journal is stored locally in %LOCALAPPDATA%\jotly\data. Local storage and exported backups are not encrypted. Use the backup feature regularly and keep a copy somewhere safe. There is no cloud backup service.

Where can I report a bug or suggest a feature?

Open an issue on GitHub. Include your app version and the steps to reproduce the problem. Please redact account details and private trading information.
